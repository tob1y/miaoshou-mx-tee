可用产品目录: E:\tk-miaoshou-rework\clean_rebuild

====================
一、先填密钥
====================
编辑 config\settings.yaml：

  miaoshou.app_key     = 开放平台 App ID / AppKey
  miaoshou.app_secret  = App Secret

权限需包含 TikTok 采集箱相关接口。
若 shops 报签名错误，把 sign_join 改成 ampersand 再试。

====================
二、放素材
====================
把底衫图放到:
  assets\blank_tees\
按文件名排序，主图不足 9 张时会规划补齐（本地路径会记在预览里；上传URL接口待补）。

====================
三、改方案（颜色等）
====================
config\schemes\default.json     默认黑白
config\schemes\six_colors.json  六色

字段 allowed_colors 可改，例如:
  ["black","white","pink"]

====================
四、命令
====================
cd /d E:\tk-miaoshou-rework\clean_rebuild

python -m pip install -r requirements.txt

# 1) 本地样例（不连网）
python main.py dry-run

# 2) 测 API 签名/店铺权限
python main.py shops

# 3) 预览真实采集箱商品（不写回）
python main.py preview --detail-id <采集箱detailId> --shop-id <店铺ID>

# 4) 确认预览后写回 + 回读校验
python main.py apply --detail-id <detailId> --shop-id <shopId> --confirm

指定方案:
  python main.py preview --detail-id ... --shop-id ... --scheme six_colors
